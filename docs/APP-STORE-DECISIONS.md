# Submission decisions

## iPhone only (`ios.supportsTablet: false`)

Claiming iPad support costs a required 13-inch screenshot set and, more to the
point, adds an iPad layout for a reviewer to judge. `Screen` caps content at
720pt, so on a 13-inch iPad the app is a phone-width column floating in a lot
of empty space — the shape Apple rejects under Guideline 4.2 as "an iPhone app
blown up". Every co-host uses a phone.

Reversible: flip the flag, add a real iPad layout, add the screenshots.
